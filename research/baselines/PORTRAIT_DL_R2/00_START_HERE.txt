A3 세로형 한식 양개창 — 통합 CNC 패키지
Revision PORTRAIT_DL_R2
====================================================

이 폴더가 유일한 제작 기준입니다.
from_claude/, from_codex/ 는 이 패키지가 대체한 이전 자료이며 혼합 사용 금지입니다.

확정 규격
- 완성 외곽: 폭463 x 높이586 mm. 세로형, 좌우로 여는 양개창.
- 창짝: 폭187 x 높이500 mm, 좌우 각각1개.
- 창살: 창짝당 세로2 + 가로4 (2026-09-10 확정). 창짝당 교차점8개, 전체16개.
- 창살 빈칸: 약35.67 x 80 mm.
- A3 그림: 폭297 x 높이420 mm, 고정틀 뒤에 한 장으로 설치.
- 원판: 1220 x900 x20 mm. 모든 부품의 길이 방향은 목리(+X)와 평행.
- 목재24개 / 기본 pocket104개 / R3.2 도그본48개 / 결합52쌍.

폴더 구성
  01_plan/   계획 문서. 무엇을 왜 이렇게 만들었는지.
  02_cnc/    실제 제작 파일과 생성·검증 소스.
  package_manifest.json  전체 파일의 경로·크기·SHA-256.

가장 중요한 원칙: 규격 원본은 한 곳뿐입니다
02_cnc/design_parameters.json 만이 규격 원본입니다.
design_spec.json, DXF, PNG, CSV, README.txt는 전부 생성물입니다.
치수나 창살 개수를 바꾸려면 design_parameters.json만 수정한 뒤 재생성하십시오.
생성물을 직접 손으로 고치면 다음 재생성에서 사라지고, 검증에서 불일치로 걸립니다.

재생성 방법 (02_cnc 폴더에서 실행)
  cd 02_cnc
  python -m venv .venv && ./.venv/bin/pip install -r requirements.txt
  ./.venv/bin/python build_portrait_double_leaf.py
검사만 다시 실행:
  ./.venv/bin/python build_portrait_double_leaf.py --validate-only
다른 패키지의 규격과 대조:
  ./.venv/bin/python generate_spec.py --compare <다른 design_spec.json>
파일 무결성 확인 (읽기 전용. 패키지 전체. 불일치 시 종료코드1):
  ./.venv/bin/python verify_package.py
매니페스트를 다시 기록해야 할 때만:
  ./.venv/bin/python verify_package.py --write

검증 상태
- 저장한 DXF를 ezdxf로 다시 읽어 59개 명목 CAD 검사 PASS.
- 기대값은 design_spec.json이 아니라 design_parameters.json에서 다시 유도합니다.
- 창살 간격만은 유도값을 쓰지 않고 조립된 도형에서 직접 재어 확인합니다.
  생성기와 검증기가 공유하는 간격 함수가 틀려도 드러나게 하기 위해서입니다.
- 홈 깊이는 두께의 정확히 절반이어야 하며, 파라미터 단계와 3차원 간섭 검사
  양쪽에서 확인합니다. 깊이가 어긋나면 결합부에 실제 겹침 부피가 생깁니다.
- 창짝은 높이/폭 2.6 이상이어야 합니다(현재 500/187 = 2.674). 파라미터 단계에서
  거부하고, 저장 DXF에서도 조립 도형으로 다시 잽니다. 외곽과 그림 여유를 함께
  키우면 다른 관계식은 모두 지키면서 창짝만 정사각형 쪽으로 무너질 수 있습니다.
- 최소 부품 간격12 mm, 최소 원판 여유20 mm, 부품 외접범위 X20~1111 / Y20~304.

재현성 — 산출물마다 조건이 다릅니다
- 빌드는 PYTHONHASHSEED=0으로 스스로 재실행하고 DXF 메타데이터를 상수로 고정합니다.
- DXF: 같은 파라미터면 항상 같은 바이트입니다. 폰트 환경과 무관합니다.
  즉 CAM에 넣는 파일은 어느 기계에서 다시 만들어도 동일합니다.
  DXF 해시가 달라졌다면 파라미터나 코드가 바뀐 것입니다.
- PNG: 같은 폰트 파일과 같은 Pillow 버전이 잡힐 때만 같습니다.
  HANOK_FONT만 바꿔도 모든 검사는 그대로 통과하면서 PNG 5장이 전부 달라집니다.
  PNG 해시만 달라졌다면 먼저 폰트 환경을 확인하십시오.
  실제로 사용된 폰트는 02_cnc/validation_report.json의 render_environment와
  02_cnc/requirements.txt 주석, package_manifest.json에 기록됩니다.
- 그 대신 DXF 헤더의 생성일시와 GUID는 의미 없는 고정값입니다. 이 도면이 어느
  리비전인지는 원판 도면 우측 상단의 REVISION 표기와 문서 메타데이터에 있습니다.
- 정확한 파일 해시는 validation_report.json 과 package_manifest.json 참고.

가공·제작 전 필수 확인
모든 기본 pocket은 명목10 mm 깊이. DOGBONE은 대응 pocket과 합집합으로 처리.
가공면A는 F01/S01/L01에서 앞쪽, F02/S02/L02는 조립 시 뒤집어 뒤쪽.
개방형 반턱은 공구가 폐기재 쪽으로 진행하도록 CAM에서 개방 경계를 처리해야 함.
HINGE_REF/LATCH_REF는 생산 가공에서 제외. 경첩/나사/캐치/후판은 제품 미확정.
명목10.00 끼움 치수는 시험편으로 실제 공차 확인 필요.
원목 상태, 고정 지그, 절삭 조건, 실제 개폐·하중·벽고정 승인은 PENDING.
실제 CAM toolpath나 G-code, 기계운전 조건은 포함하지 않았습니다.

검증 PASS는 명목 CAD geometry의 합격이며 실제 제작 완료나 개폐 보증이 아닙니다.
