## 검증 확대 진행

동일 글꼴의 실제 PNG 픽셀과 DXF·검증 JSON의 오차 한도를 검사하고 변조를 거절하는
시험 6개가 통과했다. 공식 MCP SDK와 Chrome의 실제 생성·검증·도면·다운로드도 통과했다.
Python 3.12.14·3.13.15 전체 실행에서는 추가 예제와 LLM의 예제 목록 불일치 한 건을
찾아 수정했고, 각 버전의 LLM 27개 시험을 재실행했다. 원격 CI 확인은 마지막 변경 후 수행한다.
