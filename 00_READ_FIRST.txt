한옥 창호 설계와 생성기 — 폴더 안내
====================================================

창 외경 또는 내경·창살 수·단문/양문으로 새 설계를 생성하려면 generator/README.md 를 여십시오.
generator/는 범용 생성기 0.3(생성 엔진 0.2.0)이며, unified/는 기존 확정 설계 R3의 보존 기준입니다.
두 경로 모두 명목 CAD 검증이며 실제 제작용 공차·하드웨어·CAM 확인은 PENDING입니다.

  generator/               → 외경/내경 기준 입력·프리셋·단문 좌우/양문·창살 0개 지원.
                              작업별 패키지 생성 CLI, 무결성 검사, 회귀 시험.
                              브라우저 화면은 generator/web-start.command 를 두 번 누르거나
                              generator/ 에서 ./web.sh start. 끌 때는 web-stop.command 또는 ./web.sh stop
                              새 산출물은 generator/output/packages/ 아래에 생성합니다.

  unified/                → 현재 기준. Revision PORTRAIT_DL_R3.
                            먼저 unified/00_START_HERE.txt 를 여십시오.
    01_plan/              계획 문서. 두 선행 계획서를 합친 MERGED_PLAN.md,
                            항목별 대조표, 구조 통일·결함 수정 이력.
    02_cnc/               DXF, PNG 5장, 부품·홈 좌표표, 검증 리포트,
                            그리고 이 모두를 다시 만드는 파라미터와 소스.
    03_tests/             R2 설계 회귀 기준, 소수 입력·결함 주입 시험, 실행 기록.

이전 리비전 (git 태그로 보관)
태그 R1·R2·R3·v0.2.0은 모두 첫 커밋 d974f4a를 가리키며, 그 커밋에 아래 폴더가 그대로 있습니다.
작업 트리에서는 정리했으므로 필요할 때 git checkout R1 -- from_codex 처럼 복원하십시오.

  from_codex/             → PORTRAIT_DL_R1. 창살 패턴은 현재와 같지만 규격을 손으로 관리하던 버전.
                            계획서 원본(01_prompt/)이 병합본의 뼈대가 되었습니다.
  from_claude/            → 창살 세로1 + 가로5 안. 2026-09-10에 세로2 + 가로4로 확정하면서 미채택.
                            중앙 맞댐부에 반턱을 넣지 않는 이유 등 고유 내용은 병합본에 흡수했습니다.
  research/               → R2 보관본(baselines/)과 범용 생성기 요건 조사·검토 기록.
                            unified/03_tests 의 R2 DXF 대조(--record)에는 research/baselines/ 가 필요합니다.

unified/ 문서가 가리키는 from_codex·from_claude·research 경로도 위 커밋에서 볼 수 있습니다.

혼합 사용 금지
각 패키지의 DXF는 해당 패키지 안의 부품표·홈 좌표·가공 지침과 함께 사용하십시오.
generator/가 생성한 설계도 패키지별로 관리하며 다른 입력의 산출물을 섞지 마십시오.
태그에서 복원한 이력 DXF, 특히 from_claude의 DXF는 CAM에 넘기지 마십시오.

확정 규격 요약
- 완성 외곽 463 x 586 mm, 창짝 187 x 500 mm 좌우 2짝, 중앙 고정 기둥 없음
- 창살 창짝당 세로2 + 가로4, 빈칸 약 35.67 x 80 mm
- A3 그림 297 x 420 mm 한 장을 고정틀 뒤 별도 후판에 설치
- 원판 1220 x 900 x 20 mm 한 장, 목재 24개

통합 경위와 변경 내역은 unified/01_plan/SPEC_UNIFICATION.md 에 있습니다.
