# 사용자 프로그램과 제작 확인

2026-09-27 현재 사용자가 실제 테스트 가능한 프로그램이 없다고 확인했다.
AI·DWG의 직접 열기와 실물 제작은 **미확인**이다. 자동 시험의 PASS는 이 상태를
바꾸지 않는다. 확인할 환경이 준비되면 아래 기록에 실제 결과를 추가한다.
남은 직접 확인은 [이슈 #45](https://github.com/kcenon/hanok_window/issues/45)에서 추적한다.

## 확인할 파일

`examples/double_r3.json`과 `examples/artwork_a2.json`으로 만든 패키지를 사용한다.
패키지 ID와 각 파일의 SHA-256을 먼저 기록하고 `hanok-window verify`로 무결성을
확인한다. DWG는 해당 패키지의 DXF에서 내려받으며 변환기 버전과 DWG 해시도 적는다.
확인한 파일이 바뀌면 이전 결과를 그대로 이어 쓰지 않는다.

### AI

- [ ] 대상 프로그램 이름·정확한 버전·운영체제와 파일 해시 기록.
- [ ] 복구 또는 가져오기 오류 없이 열리는지 확인.
- [ ] R3의 레이어 7종 확인: `BOARD_BOUNDARY`, `CUT_THROUGH`, `POCKET_10MM`,
  `DOGBONE`, `HINGE_REF`, `LATCH_REF`, `PART_ID`.
- [ ] 문서의 원판 외곽을 mm로 측정해 1220 × 900인지 확인. 페이지에 맞추는
  배율 변환 없이 실제 좌표가 보존돼야 한다.
- [ ] 부품 F01의 길이·폭을 같은 패키지 `parts_manifest.csv`와 비교.
- [ ] 도그본 원호, 폐곡선, 부재 번호 누락 여부와 참고 레이어 구분 확인.
- [ ] 액자형 A2의 뒤틀 B01·B02가 보이고 부품표와 일치하는지 확인.

AI는 원판 가공 도형을 담는다. 조립·열림·결합 상세도는 DXF와 PNG에서 확인한다.

### DWG

- [ ] 대상 CAD 이름·정확한 버전·운영체제, ODA 버전, 파일 해시 기록.
- [ ] AutoCAD 2010 형식을 오류 없이 열 수 있는지 확인.
- [ ] 단위 mm, 원판·부품 치수와 레이어가 같은 패키지 DXF와 일치하는지 확인.
- [ ] 원호·폐곡선·조립도·상세도·열림도와 액자형 숨은선 확인.
- [ ] 필요하면 저장 후 다시 열어 도형과 레이어 보존 확인.

자동 DWG 왕복 시험은 ODA가 설치된 Windows CI에서 수행한다. 대상 사용 프로그램의
직접 열기를 대신하지 않으며, 변환기 설치 실패로 건너뛴 실행은 왕복 검증 근거가 아니다.

## 제작 확인

실물 시험 결과는 아직 없다. 명목 치수를 합격으로 표시한 CAD 패키지에도 아래
사항이 남는다. 시험 전에는 가공 승인 상태를 바꾸지 않는다.

- [ ] 목재 종류·실제 두께·함수율·결 방향과 부재 상태 기록.
- [ ] 반턱·홈·도그본 시험편의 측정값과 끼움 상태, 적용 공차 기록.
- [ ] 실제 경첩·나사·캐치·후판·걸이 선정, 체결 여유와 하중 확인.
- [ ] 조립·개폐 중 간섭, 뒤틀과 화판 고정, 장기 변형 검토.
- [ ] 가공자가 CAM 합집합·공구 보정·개방 경계와 고정 방법을 검토.
- [ ] 시험 가공과 조립 결과, 확인자·날짜·관련 파일 및 승인 범위 기록.

## 결과 기록 양식

| 항목 | 기록 |
|---|---|
| 확인자·날짜 | 미확인 |
| 입력 예제·패키지 ID | 미확인 |
| 파일명·SHA-256 | 미확인 |
| 프로그램·버전·OS / 장비·재료 | 미확인 |
| 관측값·측정 단위·배율 | 미확인 |
| 오류·누락·불일치 | 미확인 |
| 증거 파일·스크린샷·측정 기록 경로 | 미확인 |
| 판정과 확인 범위 | 미확인 |

대상 프로그램이나 실물 시험이 제공될 때까지 미확인 항목은 후속 작업에 남긴다.
