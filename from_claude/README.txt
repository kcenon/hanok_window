3. 결합부 (Joinery)
--------------------------------------------------------------------------------
 J1  고정 창틀 모서리 반턱  40 x 40 x d10   F01(FACE A) + F02(FACE B)   4모서리
 J2  창짝 모서리 반턱      30 x 30 x d10   S01(FACE B) + S02(FACE A)   8모서리
 J3  창살 x 창살 반턱      10 x 10 x d10   L01(FACE B) + L02(FACE A)   10교차점
 J4  창살 끝단 x 창짝      10 x 10 x d10   창짝측 pocket 24개 + 창살 끝단 반턱
 J5  중앙 맞선부          단순 맞댐, 간극 3, 목재 가공 없음

 두께 배분 (z=0 뒷면 FACE B, z=20 앞면 FACE A)
   J1 : F01 z0-10 잔류 / F02 z10-20 잔류 → 합 20
   J2 : S01 z10-20 잔류 / S02 z0-10 잔류 → 합 20
   J3 : L01 앞면 z10-20 연속 / L02 뒷면 z0-10 연속 → 앞뒤 동일 평면
   J4 : 창살 끝 촉(z10-20)이 창짝 pocket에 안착 → 면 일치

 Dog-bone
   내부가 막힌 코너는 J4 창짝측 pocket 뿐이다.
   S01 4개 x 5홈 x 2코너 = 40,  S02 4개 x 1홈 x 2코너 = 8,  합계 48개 (R3.2)
   J1 / J2 / J3 및 창살 끝단 반턱은 열린 rebate이므로 dog-bone 없음.

 J5 관련 주의
   맞선측 S01 바깥 모서리에 전장 반턱(단턱 맞선)을 임의로 추가하지 말 것.
   그 반턱은 J2 모서리 반턱과 같은 지점에서 만나 반대 면일 경우 모서리에
   30 x 8 관통 구멍을 만들고, 같은 면으로 맞추려면 좌우 창짝을 거울상으로
   가공해야 해서 부품 종류가 두 배가 된다. 본 도면은 단순 맞댐 + 간극 3을 채택했다.
   가로형(v2)에서는 정수 치수를 얻기 위해 맞선 간극만 4였으나, 세로형에서는
   3으로도 모든 부품 치수가 정수로 떨어져 사방 간극이 3으로 통일된다.

 POCKET_10MM         모든 반턱/결합 홈 (깊이 10.0)
 DOGBONE             내부 코너 relief R3.2
 HINGE_REF           경첩 참고 가공 (깊이 2, 참고값)
 LATCH_REF           걸쇠 / 꽂이쇠 / 손잡이 참고 위치 (참고값)
 PART_ID             부품 번호 (annotation)
 DIMENSIONS          치수 (annotation)
 GRAIN_DIRECTION     나뭇결 방향 화살표
 ASSEMBLY_REFERENCE  완성 조립 참고도 + J1~J5 결합 상세도
 ASSEMBLY_A3         조립 참고도의 A3 그림 외곽 (파선)
 SWING_REF           개폐 방향 기호 (꼭짓점 = 경첩측)
 NOTES               제작 주석 / layer 범례

 * 관통 절삭과 pocket은 서로 다른 layer.
 * 가공 깊이가 다른 geometry(관통 20 / pocket 10 / 하드웨어 참고 2)는 전부 분리.
 * CAM toolpath는 포함하지 않는다.
 * 상세도는 확대 축척(4:1, 6:1, 8:1)이므로 절삭에 사용하지 말 것.
   원목판 영역의 절삭 geometry는 전부 1:1 이다.

5. CNC 가공 깊이 / 셋업
--------------------------------------------------------------------------------
 가공면 배정 (모든 부품이 단면 가공으로 끝난다)
   FACE A (앞면, z=20 쪽) : F01, S02, L02
   FACE B (뒷면, z=0  쪽) : F02, S01, L01

 권장 가공 순서
   SETUP 1  원목판 FACE A를 위로 고정, 도웰 기준핀 2개로 위치 기준 확보
            FACE A 부품(F01, S02, L02)의 POCKET_10MM 가공, 깊이 10.0
   SETUP 2  판을 뒤집어 동일 기준핀에 재고정 (CAM에서 X 미러 필요)
            FACE B 부품(F02, S01, L01)의 POCKET_10MM 가공, 깊이 10.0
   SETUP 3  DOGBONE (해당 pocket과 같은 셋업에서 처리 가능)
   SETUP 4  HINGE_REF / LATCH_REF — 하드웨어 확정 후에만 가공 (깊이 2 참고값)
   SETUP 5  CUT_THROUGH 관통 절삭 20.0 + 스페이서 보드 1~2mm 오버컷

 절삭 파라미터 참고
   반턱 pocket 2~3 pass (3.5~5mm/pass), 관통 절삭 4~5 pass
   기준핀은 원목판 상부 여유 영역(대략 y 320~880)에 잡으면 부품과 겹치지 않는다.
   L02는 길이 147, 폭 10의 작은 부품이 10개다. 절삭 중 이탈 위험이 가장 크므로
   부품당 탭 3개 이상을 반드시 넣을 것.
   공차: 도면은 공칭치수다. 반턱 폭에 0.1~0.2 여유를 주면 조립이 쉬워진다.

6. 조립 순서
--------------------------------------------------------------------------------
 1) 전 부품 가공면 확인, 사포(#180~#240) 마감, 홈 내부 버 제거.
    부품을 좌측 창짝 / 우측 창짝 / 고정틀 세 무더기로 분류한다.

 2) 창살 격자 선조립 (창짝 1짝씩, 총 2회 반복)
    - L02(가로 창살) 5개를 뒷면 기준으로 눕힌다.
    - L01(세로 창살) 1개를 5개 교차점에 맞춰 반턱끼리 끼운다.
    - 세로 창살이 1개뿐이라 격자만으로는 형태가 유지되지 않는다.
      3)의 창짝 조립까지 한 번에 이어서 진행할 것.
    - 앞면 = L01, 뒷면 = L02. 앞뒤 표면이 동일 평면인지 확인한다.

 3) 창짝 조립 (2짝)
    - S02(하부 가로재)의 J4 홈 1곳에 L01 하단 촉을 안착.
    - S01(좌·우 세로재)의 J4 홈 5곳씩에 L02 양끝 촉을 안착.
    - S02(상부)를 덮고 J2 모서리 반턱 4곳을 맞춘다.
    - 대각선 치수(187 x 500 → 약 533.8)를 측정해 직각을 확인한 뒤 클램핑.
    - 두 짝의 대각선 차이가 1mm를 넘으면 중앙 맞선부에 틈이 벌어진다.

 4) 고정 창틀 조립
    - F01 2개 + F02 2개를 J1 반턱으로 맞물려 463 x 586 사각을 만든다.
    - 대각선(약 746.8) 확인 후 클램핑.

 5) 접착
    - 목공용 PVA 본드를 반턱면에만 얇게 도포, 30~60분 클램핑, 24시간 양생.

 6) 가조립 및 맞선 조정
    - 고정틀을 평평한 바닥에 눕히고 두 창짝을 개구부 안에 올려 놓는다.
    - 사방 간극 3과 중앙 맞선 간극 3이 균등한지 확인한다.
    - 폭 방향 배분: 3 + 187 + 3 + 187 + 3 = 383 (고정틀 개구부 폭)
    - 높이 방향 배분: 3 + 500 + 3 = 506 (고정틀 개구부 높이)
    - 어긋나면 맞선측 S01 바깥 모서리를 대패로 미세 조정한다.
      J2 모서리 반턱 부위까지 깎지 말 것.

 7) 경첩 설치 (하드웨어 확정 후)
    - 경첩 4개, 짝당 2개(상·하). 좌측 창짝은 F01-1(좌측틀), 우측 창짝은 F01-2에.
    - 경첩 참고 위치: 창짝 하단에서 80~120, 380~420 구간.
    - 창짝이 500 높이에 187 폭으로 세장비가 크다. 경첩 2개로 충분하지만
      상·하 경첩 간격을 300 이상 확보해야 처짐이 억제된다(본 도면 기준 300).
    - 임시 스페이서(두께 3)를 사방에 끼운 상태로 경첩 자리를 잡는다.

 8) 맞선 하드웨어 설치
    - 좌측 창짝을 고정짝으로 하여 맞선측 S01-2 상·하에 꽂이쇠(flush bolt)를 달고
      F02 상·하 고정틀의 대응 위치에 받이 구멍을 낸다.
    - 우측 창짝을 작동짝으로 하여 손잡이와 걸쇠(또는 자석 캐치)를 단다.
    - 닫힘 순서: 좌측(고정짝) → 우측(작동짝).

 9) A3 그림 고정
    - 그림은 두 짝에 걸쳐 있으므로 창짝이 아니라 **고정틀 뒷면에 별도 백보드**로
      고정한다. 창짝에 붙이면 문이 열릴 때 그림이 찢어진다.
    - 백보드 유효 노출 면적 317 x 440, A3 297 x 420(세로)은 상하좌우 각 10 물림.

10) 마감 도장 — 조립 후 도장 시 홈 내부 도료 고임 주의.

7. 실제 제작 전 반드시 확인할 항목
--------------------------------------------------------------------------------
 [ ] 원목판 실측 두께가 20.0 인지 확인. 다르면 모든 pocket 깊이를
     (실측두께 / 2)로 재계산. 반턱은 두께의 정확히 절반이다.
 [ ] 목재 함수율 8~12% 확인. 세로로 긴 창짝은 함수율 변화에 따른 폭 방향
     수축·팽창이 맞선 간극에 그대로 나타난다.
 [ ] 창짝 세장비 확인. 187 x 500 창짝은 폭 대비 높이가 2.7배다.
     경첩측 S01(500 길이)의 나뭇결이 길이 방향과 평행한지 반드시 확인할 것.
     결이 어긋난 판재를 쓰면 창짝이 휜다.
 [ ] 여닫이 방향(안여닫이 / 밖여닫이) 결정. 경첩 종류와 자리파기 면이 달라진다.
 [ ] 경첩·꽂이쇠·걸쇠·손잡이 제품 선정 후 HINGE_REF / LATCH_REF 치수를
     제품 실측값으로 교체. 현재 값(길이 40 / 깊이 2)은 참고용이며 확정치가 아니다.
 [ ] 시험 절삭: 10 x 10 홈 1개와 창살 끝단 1개를 먼저 가공해 끼움감 확인.
 [ ] 뒤집기(SETUP 2) 기준핀 위치가 부품 영역과 겹치지 않는지 CAM에서 확인.
 [ ] A3 그림 백보드와 고정 방식(턴버튼 / 압착 프레임)은 이 도면에 포함되어 있지 않다.
 [ ] 고정 창틀을 벽·가구에 설치할 나사 구멍도 포함되어 있지 않다.
     세로형은 무게 중심이 높으므로 벽 고정 시 상부 고정점을 반드시 잡을 것.
