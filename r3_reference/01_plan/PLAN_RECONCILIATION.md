## 1. 완전히 일치한 항목

두 계획서가 독립적으로 같은 값에 도달한 부분이다. 병합본에 그대로 채택했다.

완성 외곽 463 × 586 / 고정틀 폭 40 / 고정틀 내부 383 × 506

외곽 치수와 도그본 수량이 서로 다른 경로로 같은 값에 도달했다는 점이 치수 사슬의
정합성을 뒷받침한다.

## 2. 충돌 항목과 판정

### 2.1 창살 구성 — 유일한 실질적 설계 충돌

| | C (미채택) | X (채택) |
|---|---|---|
| 창짝당 창살 | 세로 1 + 가로 5 | **세로 2 + 가로 4** |
| 창짝당 격자 | 2열 × 6단 | **3열 × 5단** |
| 빈칸 | 58.5 × 65 | **약 35.67 × 80** |
| L01 / L02 수량 | 2 / 10 | **4 / 8** |
| 창짝당 교차점 | 5 | **8** |
| 전체 교차점 | 10 | **16** |
| J3 홈 | 20 | **32** |
| 기본 홈 합계 | 92 | **104** |
| 결합쌍 | 46 | **52** |

**판정 근거**: 2026-09-10 사용자 확정. C의 논리("칸이 정사각형에 가깝도록")도 타당하나,
확정된 것은 X이다.

부품 수(24개)와 도그본 수(48개)는 두 안이 같다. 도그본이 같은 이유는 창살 끝 개수가
`(세로+가로) × 2끝 × 2짝 = 24`로 동일하기 때문이다(1+5 = 2+4 = 6).
반면 교차점 수는 곱(1×5 = 5 vs 2×4 = 8)이라 달라진다.

> 두 안은 별개 설계가 아니라 같은 파라미터 공간의 두 점이다. 병합본의 파라미터 파일에서
> 창살 개수 두 값만 바꾸면 미채택안도 그대로 재생성된다. 실제로 1+5로 재생성해
> 92홈 / 46쌍 / 도그본 48개가 나오고 전 검사를 통과함을 확인했다.

### 2.2 가공면 배정 — 둘 다 정합, 표현이 다름

| 부품 | C | X / 병합본 |
|---|---|---|
| F01 | FACE A, 잔류 z0–10 | A면 FRONT, 잔류 z0–10 |
| F02 | FACE B, 잔류 z10–20 | A면 BACK, 잔류 z10–20 |
| S01 | FACE **B**, 잔류 z10–20 | A면 **FRONT**, 잔류 z0–10 |
| S02 | FACE **A**, 잔류 z0–10 | A면 **BACK**, 잔류 z10–20 |
| L01 | FACE B | A면 FRONT |
| L02 | FACE A | A면 BACK |

C는 고정틀과 창짝의 면을 서로 반대로 배정했고, X는 **수직재 FRONT / 수평재 BACK**으로
통일했다. **두 방식 모두 성립한다.** F01과 S01은 간극 3으로 떨어져 있어 결합하지 않으므로
서로 다른 면을 써도 무방하다. 각 결합쌍 내부에서 상보성만 지키면 된다.

**판정**: X. 규칙이 "수직 대 수평" 한 줄로 서술되고, 모든 결합이 수직재 × 수평재이므로
쌍의 상보성이 자동으로 보장된다. 병합본은 이 성질을 결합부 유도 규칙의 근거로 삼는다.

### 2.3 경첩 위치

| | C | X / 병합본 |
|---|---|---|
| 창짝 로컬 기준 | 80~120, 380~420 (중심 100, 400) | 끝에서 60씩 (중심 60, 440) |
| 상하 경첩 중심 간격 | 300 (최소값으로 명시) | **380** |
| 조립 좌표 Y | — | 103, 483 |

**판정**: X. C가 "300보다 좁히지 말 것"을 하한으로 제시했고 X의 380은 이를 만족한다.
C의 하한 근거(창짝 세장비가 크다)를 병합본 10절에 문장으로 남겼다.

### 2.4 맞댐부 하드웨어

| | C | X / 병합본 |
|---|---|---|
| 방식 | 꽂이쇠(flush bolt) + 고정짝/작동짝 닫힘 순서 | 독립 캐치 2개 |
| 손잡이 | 작동짝 맞댐측 S01 중앙 | S01-2, S01-3 각 1개 |

**판정**: X를 구현하되 C를 **미결 항목으로 승격**. 양개창에서 닫힘 순서를 정해야 한다는
C의 지적은 유효하나 현재 설계는 독립 캐치만 위치 참고로 둔 상태다. 병합본 10절에
"미결 — 닫힘 순서와 맞댐부 보조 하드웨어"로 명시하고, 20절 PENDING 2번에 올렸다.

### 2.5 Layer 구성

C는 `ASSEMBLY_A3`(A3 외곽 전용)와 `SWING_REF`(개폐 방향 기호)를 별도 layer로 두었다.
X는 `ASSEMBLY_REFERENCE` 하나에 담고 **선종(linetype)으로 구분**한다.

**판정**: X. layer 수가 줄고, "A3와 개구부가 서로 다른 선종인가"를 자동 검사로 강제할 수
있다(`A3_and_picture_region_distinct_linetypes`). C의 의도(둘을 시각적으로 구별)는 충족된다.

### 2.6 Nesting 배치

| | C | X | 병합본(R3, R2 설계 계승) |
|---|---|---|---|
| 방식 | 참고 배치 8행 | 기준 배치 9행 | **알고리즘 유도, 8단** |
| 스택 높이 | 284 | 326 | **304** |
| 최대 행 폭 | 1101 | 1081 | **1111** |

C와 X 모두 좌표를 손으로 적었다. 병합본은 `(계열, 부재폭)` 단위 선반 채우기로 계산한다.
결과는 24개 중 16개가 X의 기준 배치와 동일하고, 가로 창살 8개만 이동해 한 단이 줄었다.
C가 강조한 "offcut을 한 덩어리로 모을 것"은 병합본 11절에 유지했다.

### 2.7 검증 체계

| | C | X | 병합본(R3, R2 설계 계승) |
|---|---|---|---|
| 저장 전 검사 | 24항목 전체 (13절 "파일을 저장하기 전에") | 검사표 전체 (12절 "저장 전·후", 생성 보고서 53개) | 64개 전체 (`IN_MEMORY_BEFORE_SAVE`) |
| 저장 후 재읽기 | DXF를 다시 읽어 geometry·부품 수 확인 (407–408행) | 검사표 전체를 다시 적용 (12절) | 64개 전체를 다시 적용 (`READ_BACK_FROM_SAVED_DXF`) |
| 렌더링 육안 확인 | nesting 이미지로 홈 누락 확인 (408행) | 저장 DXF에서 nesting·상세 렌더링, 모든 홈·도그본 확인 | X와 같음 (15절) |
| 형식 | 24항목 체크리스트 | 30행 표 | **자동 검사 64개** |
| 기대값 출처 | 문서 | 문서 | **파라미터에서 재유도** |

**판정**: 저장 후 재읽기와 렌더링 육안 확인은 **두 계획서의 공통 요구사항**이다.
병합 초판은 C를 "저장 전"으로만 분류했는데, 13절 첫 문장만 보고 C의 마지막 지시
(407–408행)를 빠뜨린 오분류였다.

실제 차이는 재읽기한 파일에 **무엇을** 다시 검사하느냐다. C는 24항목을 저장 전에 적용하고
재읽기 후에는 geometry와 부품 수를 지시한다. X는 같은 검사표 전체를 재읽기한 파일에 다시
적용한다. 병합본은 X를 따른다. 저장·재읽기에서 달라질 수 있는 것은 부품 수만이 아니며
(곡선 bulge, xdata 메타데이터, layer 속성 등), 결합 좌표나 도그본 반경이 어긋나도 부품 수
검사로는 드러나지 않기 때문이다. 저장 전 검사도 유지해 같은 64개를 두 시점에 적용한다.

C의 체크리스트 중 X에 없던 세 항목의 처리:

| C 항목 | 병합본 처리 | 검출 확인 (임시 복사본 주입 시험) |
|---|---|---|
| 21. 창짝 세장비 2.6 이상 | 파라미터 하한 `leaf.min_height_to_width_ratio` + `derive()` 명시적 오류 + 전용 검사 `leaf_height_to_width_ratio_at_least_2.6` | 외곽 523 × 646·여유 40 → 창짝 217 × 560(2.58): 빌드 거부. 단언을 빼도 저장 전·재읽기 모두 이 검사 하나만 실패 |
| 22. 창살 좌우·상하 대칭, 두 창짝 동일 구성 | 전용 검사 없음. 실측 빈칸 균등(`lattice_bars_evenly_spaced_in_measured_opening`) — 빈칸이 모두 같으면 개구부 중심 대칭이 따라온다 — 과 창짝 구분 없이 같은 종류 부품에 같은 좌표식을 적용하는 `all_pocket_coordinates_match_exact_formulas` | 우측 창짝 창살 1개만 2 mm 이동(결합부는 정상 유도): 두 검사 실패 |
| 24. 맞댐측 S01에 추가 가공 없음 | 전용 검사 없음. `pockets_per_part`(S01마다 정확히 6개), `total_base_pockets_104`, `all_pocket_coordinates_match_exact_formulas`, 도그본은 `48_exact_R3.2_corner_reliefs_two_per_seat` | S01-2 맞댐 모서리에 전장 10 mm 반턱 추가: 앞의 세 검사와 `52_joint_pairs_XY_match_opposite_faces` 실패 |

> **정정 (2026-09-11)**: 병합 초판은 이 세 항목을 "15절 표에 흡수했다"고 적었으나
> 세장비 검사는 존재하지 않았다. 외곽 523 × 646·여유 40에서 창짝 세장비가 2.58인데도
> 당시 58개 검사와 독립 재검증이 모두 통과했다. 대칭과 맞댐부는 위 검사들로 실제로
> 막혀 있었으나 15절 표에 행이 없어 확인할 수 없었다. 지금은 15절 표의 모든 행에
> 해당 검사 이름을 적었고, 자동 검사가 없는 행은 없다고 명시했다.

## 6. 요약

- 두 계획서는 규격 대부분이 일치했고, 실질 충돌은 창살 구성 한 곳이었다.

  파라미터에서 유도하는 방식으로 바꾸었다.
