# A3 세로형 양개창 — 통합 생성 리포트

## 이번 산출물

완성 외곽 **폭463 × 높이586 mm**, 좌우 창짝 각각 **폭187 × 높이500 mm**인 최신안을 기준으로 프롬프트와 실제 CNC 자료를 통합했다. 그림은 A3 세로형 **297 ×420 mm** 한 장이다.

이전 세로형 산출물은 프롬프트와 규격 검산 자료였지만, 이번에는 **편집 가능한 실제 DXF와 5개 PNG 도면을 새로 생성**했다. 초기 가로형 단일창 파일은 구버전 보관 폴더에 원본 그대로 보존했다.

## 프롬프트 재구성

전체 대체 프롬프트에는 실행 계약, 치수 사슬, 개별 부품 ID, 원판 nesting 좌표, 104개 홈의 부품별 좌표 계산식, 48개 도그본, 앞뒤 가공면과 조립 변환, 하드웨어 참고 범위, DXF layer 규칙, 저장 후 재읽기 검증, 산출물 폴더와 ZIP 점검 조건을 포함했다.

이 프롬프트는 이전 대화 또는 과거 파일 없이 실행할 수 있다. 과거 파일이 제공되는 경우에만 구버전 폴더에 보관하도록 했다. CAD 수치 검증과 실물 제조 승인을 별도 상태로 정의했다.

## 최신 DXF 결과

| 항목 | 실제 결과 |
|---|---:|
| 목재 부품 | 24개 |
| J1 고정틀 반턱 | 8홈 |
| J2 두 창짝의 반턱 | 16홈 |
| J3 창살 교차 반턱 | 32홈, 16개 교차점 |
| J4 끝단·창짝 안착 | 48홈 |
| 기본 pocket 합계 | 104개 |
| R3.2 도그본 | 48개 |
| 결합 대응 | 52쌍 |
| 최소 nesting 간격 | 12 mm |
| 최소 원판 가장자리 여유 | 20 mm |

모든 생산용 contour는 Model Space의 closed LWPOLYLINE이다. `CUT_THROUGH`는 관통 외곽, `POCKET_10MM`은 깊이10의 기본 홈, `DOGBONE`은 같은 깊이의 합집합 relief이다. 참고도와 annotation은 생산용 layer와 분리했다.

## 실제 수행한 검증

저장 전 검사와 **저장한 DXF의 재읽기 검사에서 각각 53개 항목을 통과**했다. 명목 치수, 부품·홈 수량, 정확한 홈 좌표, 원호/bulge, 내부 포함, 자기교차와 완전 중복, 원판 여유와 부품 간격, 목리, 조립 위치의 52쌍 대응, 앞뒤 잔존 두께 및 의도하지 않은 재료 겹침을 검사했다. 독립 `--validate-only` 실행도 통과했다.

원판 전체·홈 확대·J1~J4 상세·닫힘 조립도·열림 참고도를 DXF에서 직접 렌더링하여 시각 확인했다. 창짝 부품 ID와 손잡이 참고 표식이 겹치지 않도록 ID 위치를 정리했다. 기하학적 근거 없이 만든 렌더링을 CNC geometry 대신 사용하지 않았다.

상태는 **PASS_NOMINAL_DXF_GEOMETRY**이다. 실제 경첩과 나사, 하중 및 동시 개폐 간섭, 후판과 그림 고정, 원목 상태, 끼움 공차, 지그와 CAM 조건은 **PENDING**이다. 실제 절삭·조립 시험이나 기계운전 승인을 수행한 결과가 아니다.

## 패키지 사용

`01_prompt`에서 최신 프롬프트를, `02_CNC_current`에서 최신 제작 자료를 사용한다. `03_reference_history`는 초기 가로형 단일창과 과거 프롬프트를 보존한 폴더다. 과거 DXF 또는 과거 검증 기록을 최신 제작에 혼합하지 않는다.

PNG 도면은 영어 CAD 표기를 사용하고, 전체 프롬프트와 제작 README는 한국어로 제공한다. 재생성·검증 소스와 사용한 라이브러리 버전도 포함한다. 폰트 파일과 CAM toolpath는 배포하지 않는다.
